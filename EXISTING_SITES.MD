# Existing Sites for Reference

Simple, image-first furniture and woodworking sites, collected as design references for SOSART, Arte en Madera. See [FURNITURE.md](FURNITURE.md) and [STRATEGY.md](STRATEGY.md).

These come from web search summaries. The sites themselves have not been reviewed, so check each one before relying on it.

## Sites

| Site | Why it is relevant |
| --- | --- |
| [Croft House](https://crofthouse.com/) | Short homepage led by polished images. The only text is in the links. |
| [The Joinery](https://thejoinery.com/) | Clean layout with a high-resolution photo of each piece and a short story paragraph. Closest to the provenance idea. |
| [Parkman Woodworks](https://www.parkmanwoodworks.com/) | Simple, with product images in the spotlight. |
| [Vorrath Woodworks](https://vorrathwoodworks.com/) | Minimal, with large photos and a five-item menu (about, portfolio, capabilities, careers, contact). |
| [Pfeifer Studio](https://pfeiferstudio.com/) | Small made-to-order studio with a gallery-first layout. See its [furniture gallery](https://pfeiferstudio.com/designer-furniture-gallery/). |
| [Relic Modern](https://relicmodern.com/) | Single maker who builds each piece start to finish. Close to the workshop story. |
| [Urbandi](https://www.urbandi.com/) | Handcrafted solid-wood furniture with a simple catalog. |
| [Rotsen Furniture](https://rotsenfurniture.com/) | Wooden pieces on a plain white background. |
| [Jardan](https://www.jardan.us/) | Black lines and empty space keep the focus on the product. |
| [Projects Contemporary Furniture](https://www.projectsfurniture.com/) | Luxury showroom whose main page is one large image with no typography. |
| [George Nakashima Woodworkers](https://nakashimawoodworkers.com/) | Full-width photography, minimal navigation, and a strong story about the wood and the trees. Good model for provenance. |
| [Artisan Born](https://artisanborn.com/) | Clean layout with a large hero photo. Gives whole sections to where the wood comes from and how it is dried. |
| [Blacktail Studio](https://www.blacktailstudio.com/) | Image-forward, with a clean menu and finished pieces up front. Does not stress sourcing. |
| [Luteca](https://luteca.mx/) | Mexico City furniture brand with minimalist, photo-led pages. The one Latin American maker here, though its site is English only. |

## Patterns to Borrow

- Keep the homepage to one or two large photos and a short menu.
- Give each piece a short story paragraph next to its photos.
- Use plenty of white space and let the wood provide the color.
- Use a centered menu that goes straight into the collection.

## Gaps

Almost all of these are US makers, with one Australian and one Mexican. None is known to be bilingual or built around a WhatsApp contact, which this project needs.
